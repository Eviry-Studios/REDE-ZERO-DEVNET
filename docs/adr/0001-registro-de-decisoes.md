# ADR-0001 — Registro de decisões

**Estado:** Aceita
**Escopo:** Projeto
**Data:** 2026-09-29
**Relacionamento:** REQ-079, REQ-086, REQ-095, REQ-097

## Contexto

Os documentos normativos deixam várias decisões **A DEFINIR** (`REQUIREMENTS.md §23`, `SPECIFICATIONS.md §71`). Ao iniciar a DEVNET, parte delas precisa ser tomada para que exista código executável. Sem registro, essas escolhas viram decisões implícitas e permanentes, dependentes da memória de quem as tomou (`REQ-096`).

## Decisão

Toda decisão técnica relevante será registrada como ADR neste diretório, com escopo explícito. Decisões tomadas para a DEVNET são provisórias por definição e não autorizam sua adoção na TESTNET ou MAINNET sem nova ADR.

## Consequências

* Novos contribuidores podem entender o porquê de cada escolha (`REQ-098`).
* Discordâncias são tratadas propondo uma nova ADR que substitui a anterior.
